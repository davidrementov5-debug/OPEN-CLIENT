# OPEN CLIENT

OPEN CLIENT is an independent Minecraft: Java Edition launcher for Windows, developed using Java 21 and JavaFX.

## Features

- Modern dark-themed launcher interface
- Offline profile management
- Minecraft version selection
- Mod and resource pack management
- Microsoft account authentication integration (in development)

## Development status

OPEN CLIENT is currently under development. Minecraft Services API authorization is pending Mojang's review.

This project is not affiliated with or endorsed by Mojang Studios or Microsoft.
